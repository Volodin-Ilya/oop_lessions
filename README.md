# Game Engine — Шаблон для лабораторных работ

Образовательный шаблон простого 2D игрового движка на C++ для студентов 2 курса магистратуры группы ИВТ Воронежского государственного университета (ВГУ).

## О проекте

Шаблон предоставляет базовую инфраструктуру для реализации 2D игр и демонстраций в рамках курса "Объектно-ориентированного программирования" (ООП). Студенты заполняют функции в `Game.cpp`, реализуя игровую логику с использованием принципов ООП.

## Структура

| Файл         | Описание                                                         |
| ------------ | ---------------------------------------------------------------- |
| `Engine.h`   | Заголовочный файл движка: константы экрана, объявления функций   |
| `Engine.cpp` | Реализация движка: инициализация X11, обработка ввода, рендеринг |
| `Game.cpp`   | Шаблон игры: пустые функции, которые реализует студент           |
| `Makefile`   | Скрипт сборки                                                    |

## Игровой цикл

Движок вызывает четыре функции в порядке:

1. **`initialize()`** — инициализация данных игры
2. **`act(dt)`** — обновление логики (вызывается каждый кадр, `dt` — время с последнего кадра)
3. **`draw()`** — отрисовка кадра на backbuffer
4. **`finalize()`** — освобождение ресурсов

## API движка

### Ввод
- `is_key_pressed(int vk_code)` — проверка нажатия клавиши (VK_ESCAPE, VK_SPACE, VK_LEFT, VK_UP, VK_RIGHT, VK_DOWN, символы 'A'-'Z')
- `is_mouse_button_pressed(int button)` — проверка нажатия кнопки мыши (0 — левая, 1 — правая)
- `get_cursor_x()` / `get_cursor_y()` — позиция курсора

### Отрисовка
- `buffer[SCREEN_HEIGHT][SCREEN_WIDTH]` — backbuffer, массив 32-битных цветов (8 бит на канал R, G, B)
- `clear_buffer()` — очистка буфера нулями
- `is_window_active()` — проверка активности окна

### Управление
- `schedule_quit_game()` — запрос закрытия окна

### Логирование
- `log_f(const char* fmt, ...)` — функция логирования в файл

## Сборка

```bash
make
```

Очистка:

```bash
make clean
```

Требования:
- Компилятор g++ с поддержкой C++17
- Графическая библиотека X11

## Настройка

1. Откройте `Game.cpp`
2. Реализуйте функции `initialize()`, `act()`, `draw()`, `finalize()`
3. Соберите и запустите:

```bash
make
./game
```
